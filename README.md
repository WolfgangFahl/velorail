## Cite as

If you use velorail in your research, please cite it via its Zenodo concept DOI
(which always resolves to the latest version):

> Fahl, W., & Holzheim, T.
> *velorail — Multimodal route planning with a focus on bike and train.*
> Zenodo. https://doi.org/10.5281/zenodo.21722377

Machine-readable metadata is available in [`CITATION.cff`](./CITATION.cff);
GitHub's "Cite this repository" button and Zenodo pick it up automatically.
For a specific release, use the version DOI shown on the corresponding
[Zenodo record](https://doi.org/10.5281/zenodo.21722377).
